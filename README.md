# java-lotto-precourse
### 기능구현목록

- 로또 번호 입력
    - 숫자 범위 1~45 이외는 에러(음수, 0, 45초과)
    - 숫자 타입 에러(소수)
    - 숫자 외 에러
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
    - 랜덤 인덱스 생성하여 set에 추가, 6개가 될때까지 반복
    - 보너스 번호도 추가
        - 숫자 검증 로직 재활용
        - 배열 대신 ArrayList 사용
        - 접근할 때 OutOfIndex 주의
- 로또 번호 일치 시 1등부터 5등까지 당첨
    - 1등 : 6개 일치
    - 2등 : 5개 번호 + 보너스 일치
    - 3등 : 5개 번호 일치
    - 4등 : 4개 번호 일치
    - 3등 : 3개 번호 일치
        - set 접근시 쓰레기값 출력되지 않게 주의
- 로또 구입 금액 입력, 1장 1,000원 단위 로또 발행
    - 1,000원 단위 아니면 에러 발생
    - 음수, 0, 숫자 아님, 소수점 등 에러
- 로또번호 입력
    - 출력예시

        ```python
        1,2,3,4,5,6
        ```

        - 앞, 뒤, 사이 공백 있으면 에러
        - 1~45 사이의 양의 정수 아니면 에러
- 보너스 번호 입력
    - 출력 예시

        ```python
        7
        ```

- 당첨번호 로또 배열 생성
    - 1개의 로또를 발행하는 것과 동일
- 발행한 로또 수량 및 번호 출력, 로또 번호는 오름차순으로 정렬
    - 발행한 로또들 저장
    - 각 로또와 당첨번호 로또간의 차집합 연산 통해 결과 출력
- 수익률 계산
    - 로또 구입금액 대비 당첨금액 백분율
    - 소수점 둘째자리에서 반올림(첫째자리까지만 표시)

    ```python
    총 수익률은 62.5%
    ```

- 모든 에러 “[ERROR]”로 시작해서 문구 출력

    ```python
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    ```
