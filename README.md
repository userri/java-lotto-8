# java-lotto-precourse
### 기능구현목록

- 각 기능별 에러 발생 시 오류 메시지 출력 후 다시 입력
- 로또 구입 금액 입력, 1장 1,000원 단위 로또 구입 금액 입력
    - 1,000원 단위가 아닌 숫자 입력 시 에러 발생
    - 음수, 0, 숫자 아님, 소수점 등 입력 시 에러 발생
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑음
    - 로또 번호가 6개가 아닐 시 에러 발생
    - 로또 번호에 중복 있을 시 에러 발생
- 발행한 로또를 오름차순으로 출력
- 당첨 번호 입력
    - 쉼표로 구분된 6개의 숫자를 입력
        - 숫자 범위 1~45 이외(음수, 0, 45초과) 입력 시 에러 발생
        - 숫자 타입 잘못 입력 시(소수 등) 에러 발생
        - 숫자 외 문자 등 입력 시 에러 발생
        - 중복된 숫자가 있을 시 에러 발생
- 보너스 번호 입력
    - 숫자 범위 1~45 이외(음수, 0, 45초과) 입력 시 에러 발생
    - 숫자 타입 잘못 입력 시(소수 등) 에러 발생
    - 숫자 외 문자 등 입력 시 에러 발생
    - 당첨 번호와 중복된 숫자가 있을 시 에러 발생
- 로또 번호 일치 시 1등부터 5등까지 당첨
    - 1등 : 6개 일치
    - 2등 : 5개 번호 + 보너스 일치
    - 3등 : 5개 번호 일치
    - 4등 : 4개 번호 일치
    - 3등 : 3개 번호 일치
  
- 로또번호 입력
    - 출력예시

        ```python
        1,2,3,4,5,6
        ```

        - 앞, 뒤, 사이 공백 있으면 에러
        - 1~45 사이의 양의 정수 아니면 에러
- 보너스 번호 입력
    - 출력 예시

        ```python
        7
        ```

- 수익률 계산
    - 로또 구입금액 대비 당첨금액 백분율
    - 소수점 둘째자리에서 반올림(첫째자리까지만 표시)

    ```python
    총 수익률은 62.5%
    ```

- 모든 에러 “[ERROR]”로 시작해서 문구 출력

    ```python
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    ```
